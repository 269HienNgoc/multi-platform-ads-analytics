# Golang skills provenance

The Go skills in this directory are curated/adapted for this project from the concepts and skill catalog in:

- Repository: https://github.com/samber/cc-skills-golang
- Upstream commit: `19a0626ae8565d27a7b7bdf59d8d99d94d7e284c`
- Author: Samuel Berthe / contributors

The project-specific versions intentionally narrow upstream guidance to this repository's stack: Go 1.24, YAML configuration, Zap logging, PostgreSQL, REST APIs, multi-platform advertising adapters, native VPS deployment, and no Docker.

Upstream contains additional specialized skills (gRPC, GraphQL, Wire, Fx, Cobra, Viper, samber/* libraries, benchmarking, etc.). Add those only when the project actually adopts the corresponding technology.
